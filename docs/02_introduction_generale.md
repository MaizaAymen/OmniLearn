# General Introduction

In a digital environment in constant evolution, the ability to deliver effective, personalized learning experiences has become a major challenge for educational institutions and individual learners alike. In this context, online collaborative learning platforms occupy an increasingly important place — especially in the field of computer science education, where learners need to practice code, work in groups, and progress along a structured curriculum.

It is within this context that we developed **OmniLearn** — a complete web platform dedicated to collaborative, AI-assisted learning. The platform brings together, in a single product, features that are usually scattered across several tools: an in-browser code editor with multi-language execution, a graded problem set (free-tier and pro-tier), virtual classrooms with assignments and announcements, real-time messaging, a PDF assistant powered by Retrieval-Augmented Generation (RAG), and a personalized learning roadmap generated from the learner's goals, interests and prior skills. The application also follows up daily work through structured logs: problem solving and contributions with certification progress, AI roadmap activity with roadmap certifications, and PDF analysis traces (including quizzes and learning logs). The AI mentor guides study without giving the final solution, provides AI-assisted code correction, and a tag-based learning layer (`/ai`, `/stack-overflow`, `/youtube`) helps learners move faster with or without the AI.

The platform is designed around three complementary plans — **Free**, **Pro** and **Institution** — and four user roles — **super admin**, **institution admin**, **teacher** and **student**. The Institution plan introduces a multi-tenant model in which an organization (school, university, training center) onboards itself, invites its members through invite links, manages its own curriculum (grades, specialities, levels), creates classrooms and assigns problems to its students. The Pro plan unlocks the full problem catalogue, the AI features and advanced workspace tools for individual learners. The Free plan keeps the entry barrier low with a curated set of free problems and core messaging.

OmniLearn proposes an innovative, intuitive and secure solution that allows:

- **Students** to learn by doing — solving coding problems, using the AI mentor for guidance and code correction without direct answers, exploring `/ai`, `/stack-overflow`, `/youtube` learning tags, joining classrooms, chatting with peers, and following a roadmap tailored to their goals.
- **Teachers** to create courses, modules, lessons and assignments, manage classrooms, evaluate submissions and broadcast announcements.
- **Institution admins** to onboard their organization, define their academic structure (grades / specialities / levels), invite teachers and students, manage their member directory and monitor activity.
- **Super admins** to oversee the entire platform, manage plans, free-tier and pro-tier catalogues, and global statistics.
