# Abstract

## Summary

OmniLearn is an AI-powered learning platform for coding education. It brings
many study tools into one place: an online code editor, coding problems,
virtual classrooms, assignments, real-time messaging, and personalized
learning roadmaps. An AI mentor guides students step by step without giving
away the full answer, and a Retrieval-Augmented Generation (RAG) PDF
assistant lets learners ask questions about their own documents and get
answers grounded in the file. Teachers can create classrooms, fork problems
into their courses, run live coding sessions (with exam mode and identity
masking), and assign work with deadlines. The platform provides role-based
access control, three plans (Free, Pro, Institution), multi-tenant
organization management, Stripe billing, two-factor authentication, and
progress tracking. Built as a containerized, modern web application, it aims
to make learning to code more personal, more collaborative, and more
effective, while helping teachers manage their classrooms with less effort.

**Keywords:** AI Tutor, Coding Education, Code Editor, Deep Learning,
Docker, Express, Live Coding Sessions, Multi-Tenancy, Personalized Roadmap,
PostgreSQL, React, Retrieval-Augmented Generation (RAG), SaaS, Socket.IO.

## الملخص

منصة تعليمية ذكية مخصصة لتعلّم البرمجة، تجمع العديد من أدوات الدراسة في مكان
واحد: محرّر أكواد عبر الإنترنت، ومسائل برمجية، وفصول افتراضية، وتكليفات، ومراسلة
فورية، ومسارات تعلّم مخصّصة لكل طالب. يقدّم مرشد ذكاء اصطناعي توجيهًا تدريجيًا
للطالب دون منحه الحل الكامل، كما يتيح مساعد PDF المعتمد على تقنية التوليد المعزّز
بالاسترجاع (RAG) للمتعلّمين طرح أسئلة حول مستنداتهم الخاصة والحصول على إجابات
مستندة إلى محتوى الملف.

يستطيع الأساتذة إنشاء الفصول، ونسخ المسائل إلى دوراتهم، وإدارة جلسات برمجة
مباشرة (مع وضع الامتحان وإخفاء الهوية)، وإسناد المهام بمواعيد نهائية. توفّر
المنصة نظام صلاحيات حسب دور المستخدم، وثلاث خطط (مجانية، احترافية، ومؤسّسية)،
وإدارة مؤسسات متعدّدة بشكل مستقل، ونظام فوترة، ومصادقة ثنائية لتعزيز الأمان،
وتتبّعًا لتقدّم المتعلّمين. وقد بُنيت كتطبيق ويب حديث قابل للنشر داخل حاويات
برمجية، بهدف جعل تعلّم البرمجة أكثر تخصيصًا وتعاونًا وفعالية، مع مساعدة
الأساتذة على إدارة فصولهم بجهد أقل.

**الكلمات المفتاحية:** الذكاء الاصطناعي، تعلّم البرمجة، المرشد الذكي، محرّر
الأكواد، التعلّم العميق، الفصول الافتراضية، جلسات البرمجة المباشرة، المسارات
التعليمية المخصّصة، التوليد المعزّز بالاسترجاع، إدارة المؤسسات المتعدّدة،
قواعد البيانات، الحاويات البرمجية، أمن المعلومات، المنصّات السحابية.
