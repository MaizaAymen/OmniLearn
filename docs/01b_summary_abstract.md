# Abstract

## Summary

OmniLearn is an AI-powered learning platform for coding education. It brings
many study tools into one place: an online code editor, coding problems,
virtual classrooms, real-time messaging, and personalized learning roadmaps.
An AI mentor guides students without giving away the full answer, and a
Retrieval-Augmented Generation (RAG) PDF assistant answers questions grounded
in the learner's own documents. Teachers can run classrooms, live coding
sessions, and assignments. The platform adds role-based access, three plans,
multi-tenant management, billing, and two-factor authentication, aiming to
make learning to code more personal, collaborative, and effective.

**Keywords:** AI Tutor, Coding Education, Code Editor, Deep Learning,
Docker, Express, Live Coding Sessions, Multi-Tenancy, Personalized Roadmap,
PostgreSQL, React, Retrieval-Augmented Generation (RAG), SaaS, Socket.IO.

## الملخص

منصة تعليمية ذكية مخصصة لتعلّم البرمجة، تجمع العديد من أدوات الدراسة في مكان
واحد: محرّر أكواد عبر الإنترنت، ومسائل برمجية، وفصول افتراضية، ومراسلة فورية،
ومسارات تعلّم مخصّصة لكل طالب. يقدّم مرشد ذكاء اصطناعي توجيهًا للطالب دون منحه
الحل الكامل، كما يجيب مساعد PDF المعتمد على تقنية التوليد المعزّز بالاسترجاع
(RAG) عن الأسئلة استنادًا إلى مستندات المتعلّم الخاصة. يستطيع الأساتذة إدارة
الفصول وجلسات البرمجة المباشرة والتكليفات. وتوفّر المنصة نظام صلاحيات حسب الدور،
وثلاث خطط، وإدارة مؤسسات متعدّدة، ونظام فوترة، ومصادقة ثنائية، بهدف جعل تعلّم
البرمجة أكثر تخصيصًا وتعاونًا وفعالية.

**الكلمات المفتاحية:** الذكاء الاصطناعي، تعلّم البرمجة، المرشد الذكي، محرّر
الأكواد، التعلّم العميق، الفصول الافتراضية، جلسات البرمجة المباشرة، المسارات
التعليمية المخصّصة، التوليد المعزّز بالاسترجاع، إدارة المؤسسات المتعدّدة،
قواعد البيانات، الحاويات البرمجية، أمن المعلومات، المنصّات السحابية.
